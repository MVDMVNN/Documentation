# Создание лендинга в АIO

# Архив лендинга

Нельзя просто архивировать всю папку ленда, надо архивировать, конкретно, файлы внутри папки и этот архив уже загрузить

![Снимок экрана 2025-11-28 в 17.55.15.png](landing/create/Снимок_экрана_2025-11-28_в_17.55.15.png)

# Загружаем лендинг

![Снимок экрана 2025-11-28 в 17.36.18.png](landing/create/52f0cc10-4331-4170-8544-53b5bb6a89fb.png)

1. Переходим во вкладку “Content”
2. Переходим во вкладку “Landings”
3. Нажимаем кнопку “+ Landing”

![Снимок экрана 2025-11-28 в 17.44.39.png](landing/create/Снимок_экрана_2025-11-28_в_17.44.39.png)

1. Выбираем “Upload ZIP archive”

![Снимок экрана 2025-11-28 в 17.44.50.png](landing/create/Снимок_экрана_2025-11-28_в_17.44.50.png)

1. Вводим название ленда
2. Выбираем нужную страну
3. Выбираем нужный язык
4. Выбираем “Preland”
5. Выбираем “Simple”
6. Выбираем “Sweeps”
7. Загружаем архив ленда

# Проверяем работоспособность лендинг

Нажимаем левой кнопкой мыши на лендинг

- Через “Manage Landing” можем заменить архив или редактировать файл “index.html”, но очень часто после этого все кешиться и приходиться заново создавать лендинг
- Через “Visit by 1Step Preview Link” можем посмотреть как отображается лендинг
- Через “Share” даем доступ другим пользователям

![Снимок экрана 2025-11-28 в 18.17.49.png](landing/create/Снимок_экрана_2025-11-28_в_18.17.49.png)

# Доступы

Доступы к лендингам даем всем командам баеров, а тим лидам еще доступ на редактирование. У всех разработчиков, по умолчанию, есть к ним доступ.
