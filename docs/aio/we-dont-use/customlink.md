# CustomLink

В AIO мы можем создаваить кастомные превью для ссылок, изменяя OG tags

## 1. Создаём кампанию
2. Переходим в Generated Links

![Screenshot 2025-12-01 at 11.04.05.png](we-dont-use/customlink/Screenshot_2025-12-01_at_11.04.05.png)

## 3. Находим из списка сгенерированных сслылок нашу кампанию с нашим доменом. 
Правой кнопкой вызываем меню и выбираем Edit Link

![Screenshot 2025-12-01 at 11.06.29.png](we-dont-use/customlink/Screenshot_2025-12-01_at_11.06.29.png)

## 4. Заполняем все необходимые нам поля

В основном мы заполняем OG Title и OG Image

![Screenshot 2025-12-01 at 11.21.08.png](we-dont-use/customlink/Screenshot_2025-12-01_at_11.21.08.png)

## 5 В вкладке TECH (Domains)  мы находим наш домен и редактируем его

Нужно активировать ползунок Allow Indexing by Search Engines, чтобы поисковые скрипты могли анализировать и принимать OG теги

![Screenshot 2025-12-01 at 11.11.00.png](we-dont-use/customlink/Screenshot_2025-12-01_at_11.11.00.png)
