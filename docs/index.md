# Добро пожаловать в доку

Это тест документации

## Быстрый старт

1. Склонировать репозиторий
2. Установить зависимости
3. Запустить локальный сервер

```bash
git clone https://github.com/your-org/your-repo
cd your-repo
npm install
npm run dev
```

## Важные заметки

!!! warning "Перед началом работы"
Убедиться что есть доступ к `.env` файлу. Без него локально ничего не запустится.

!!! tip "Совет"
Использовать `Ctrl+K` для быстрого поиска по документации.
